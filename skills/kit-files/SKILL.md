# 파일과 데이터 처리

파일명, 실제 형식, 인코딩, 열/필드와 표본 데이터를 먼저 확인한다. 입력 파일을 보존하고 과제에서 지정한 산출물 경로와 형식을 따른다. 개인 파일 업로드나 외부 변환 서비스를 사용하지 않는다.

CSV는 구분자, 헤더, 누락값과 숫자/날짜 해석을 확인한다. 변환 후 행 수, 합계와 대표 값을 원본에 대조한다. 스프레드시트는 기존 수식과 표시값을 구분하고 사용 가능한 로컬 라이브러리를 우선한다. 수식을 계산하지 못했다면 계산 완료로 보고하지 않는다.

PDF는 로컬 텍스트 추출 결과와 페이지를 대조한다. 스캔본이면 설치된 로컬 OCR 가능 여부를 확인한다. 표와 페이지 레이아웃이 중요한 결과는 로컬 렌더러로 이미지화해 읽거나 사용자가 확인하게 한다. 추출 성공만으로 표의 연결과 시각 품질을 보증하지 않는다.

새 의존성과 산출물 형식은 필요한 것만 선택한다. 설치가 차단되면 제공 도구 안에서 가능한 결과와 남은 한계를 설명하고 우회하지 않는다. 로컬 처리를 위한 CLI와 파일 렌더링만 사용하며 브라우저 자동 조작과 원격 AI/OCR API는 사용하지 않는다.
