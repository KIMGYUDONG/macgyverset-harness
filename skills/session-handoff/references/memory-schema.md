# 교훈 정리와 회수

현재 대화의 에이전트가 검증한 교훈을 기록한다. 인계 시 교훈 정리를 선택하면 기존 자동 기록과 비교해 중복을 합친다. 원인 미확정 실패를 일반 규칙으로 만들지 않는다.

- 공통 교훈: 작업 공간 안에서 지정한 기억 문서의 관련 항목과 연결된 참조에 병합한다. 인덱스는 짧게 유지한다.
- 프로젝트 교훈: 기존 프로젝트 참조를 우선 사용한다. 적절한 문서가 없으면 `docs/reference/agent-memory.md`에 기록하고 프로젝트 AGENTS에서 연결한다.
- 진행 상황과 다음 작업: `docs/handoff/`에 보존한다.
- 스킬 사용법 자체의 교훈: 관련 스킬에 한정해 기록한다.

각 항목에 사실, 적용 범위, 근거와 확인 날짜, 적용 방법을 남긴다. 코드로 확인 가능한 사실은 현재 소스와 재대조한다. 최신 명확한 사용자 지시를 우선하며 상충하는 기록을 동시에 활성 규칙으로 남기지 않는다. 전역 행동 규칙 추가는 명확한 사용자 지시에 따른다. 모든 교훈을 전역 AGENTS에 복사하지 않는다.

새 세션은 현재 요청과 관련된 기억을 읽는다. 프로젝트의 진행 상황을 다른 프로젝트의 지침으로 사용하지 않는다. 별도 네이티브 백그라운드 메모리나 Claude auto-memory 설정은 이 절차에서 변경하지 않는다.
