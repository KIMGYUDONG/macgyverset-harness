# 세션 산출물 추천

다음 네 항목을 매번 같은 의미로 제공한다. 사용자가 이미 선택했다면 메뉴를 반복하지 않는다.

| 번호 | 산출물 | 추천 신호 |
| --- | --- | --- |
| 1 | 인계 문서 | 미완료, 차단, 결정 이유, 다음 작업처럼 다음 대화가 알아야 할 맥락 |
| 2 | 시작 프롬프트 | 사용자가 새 세션에서 시작하려는 구체적인 작업 |
| 3 | 교훈 정리 | 검증된 비자명한 함정, 재사용 가능한 결정 또는 명확한 사용자 선호 |
| 4 | 계획과 지침 갱신 | 실제 수용 기준을 충족한 계획 상태나 새로 확정된 작업 규칙 |

예를 들어 구현 일부와 실패한 테스트가 남았다면 1, 2를 추천하고, 새로운 함정이 입증됐다면 3을 추가한다. 단발 질문만 답한 경우 산출물이 불필요하다고 말하고 선택권만 제공한다. 추천 조합과 이유를 한 문장으로 설명한다. 선택하지 않은 문서를 만들지 않는다.

도구가 복수 선택을 지원하지 않으면 네 번호와 추천 조합을 보여주고 '원하는 번호를 알려주세요. 예: 1, 3'으로 선택을 받는다. 이 질문은 산출물 범위를 결정하며 이미 승인한 작업을 다시 승인받는 절차가 아니다.
