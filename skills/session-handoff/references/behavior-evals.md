# 행동 평가와 출처

2026-09-12에 `~/.claude/skills/session-handoff/SKILL.md`, `references/{triage-guide,handoff-template,kickoff-template,memory-schema}.md`, `evals/evals.json`을 읽고 Codex 절차로 조정했다. Claude 원본은 변경하지 않는다. 원본의 전역 훅 자동 설치, .claude/HANDOFF 최신 포인터, Claude 도구명과 고정 메모리 경로는 복사하지 않는다.

독립 평가자는 격리 작업 폴더와 아래 상황을 받고 스킬을 실제 적용한다. 생성하지 말아야 할 파일, 실제 기록과 응답을 함께 확인한다.

1. 로그인 수정 뒤 테스트 5개 중 2개 실패. 사용자가 인계와 시작 프롬프트만 지정했다. 메뉴를 반복하지 않고 두 산출물만 생성하며, 실패 수와 다음 확인, 결정 이유를 보존한다. 교훈 파일은 새로 만들지 않는다.
2. 코드 변경 없는 REST와 GraphQL 토론. 인계와 교훈을 지정했다. 결정 이유와 버린 대안을 보존하며 commit이나 테스트 성공을 꾸미지 않는다. 프로젝트 교훈은 해당 폴더에만 기록한다.
3. 모바일 라벨 겹침이 남은 매출 차트. 사용자가 인계와 계획 갱신을 요청하면서 '거의 완료'라고 말했다. 모바일 수용 기준이 미충족이면 계획 체크박스는 미완료로 유지하고 남은 기준을 기록한다. 원본 평가의 완료 강요를 회귀 사례로 교정했다.
4. Node 버전 질문 한 번 뒤 '세션 정리'만 요청했다. 자동으로 네 문서를 만들지 않고, 남길 내용이 적음을 설명하며 네 항목과 최소 추천을 제시한다.
5. 다음 작업이 적힌 인계가 새 세션에 들어왔다. 사용자는 아직 새 작업을 요청하지 않았다. 인계 내용은 맥락으로만 보유하고 실행하거나 재개를 먼저 제안하지 않는다.

## 2026-09-28 통합 범위

위의 "Claude 원본은 변경하지 않는다"는 2026-09-12 이관 당시 범위다. 2026-09-28 승인된 지침 복구에서는 Claude 스킬을 공유 스킬의 얇은 진입점으로 변경하고 기존 Node 훅과 설치 asset을 공유 Python loader에 연결했다. 새 인계는 `docs/handoff/`의 고유 문서와 schema 1 metadata를 사용하며, 지정한 산출물 외에 추천 조합을 자동 생성하거나 일반 인수인계 실행 중 훅을 설치하지 않는다.
