# 사실을 보존하는 설명

결과와 사용자 영향을 먼저 말하고 선택 이유와 검증 근거를 연결한다. 문서의 독자와 과제에서 정한 형식을 따른다. 원문에 없는 사실, 성과, 숫자와 고유명사를 추가하지 않는다.

문장마다 앞 문장의 관련 개념을 이어받아 새 정보를 더한다. 문장 길이와 종결을 자연스럽게 바꾸고 불필요한 부제목, 상투어와 기계적인 병렬을 줄인다. 코드, 식별자, 직접 인용과 수치는 보존한다. 강한 단정으로 미확인 조건을 숨기지 않는다.

윤문 후 원문과 비교해 주장, 조건과 한계가 바뀌지 않았는지 확인한다. 개인 이력서 문체나 사례를 과제에 가져오지 않는다. 후속 서술형 답안을 작성하거나 다듬는 용도로 사용하지 않는다.
