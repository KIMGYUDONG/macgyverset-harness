# 동작과 누락 검증

과제의 각 필수 동작을 구현 위치와 확인 방법에 연결한다. 빠진 기능, 임시 상수와 실제 실행되지 않는 경로를 구분한다. 변경 diff와 테스트를 읽고 계획의 핵심 항목이 구현됐는지 확인한다.

대상 기능 검사 후 영향받는 기존 기능과 중요한 오류 경계를 확인한다. 프로젝트가 제공한 typecheck/lint/test/build 중 변경에 필요한 검사를 실행하고 완료 출력과 종료 상태를 확인한다. 서버가 시작됐다는 사실만으로 기능 통과를 주장하지 않는다.

CLI/API에서 확인한 흐름과 사용자가 직접 확인한 UI를 따로 기록한다. 테스트 통과, 런타임 동작, 실제 운영 환경 검증은 서로 다른 증거다. 수행하지 않은 조건은 미검증으로 남긴다. Computer Use, Playwright와 브라우저 자동 조작은 사용하지 않는다.

명백한 실패는 재현 조건을 고정하고 원인을 좁혀 수정한다. 새 변경이나 실패가 없으면 같은 전체 검사를 반복하지 않는다. 성능 이득은 비교 조건과 측정값이 있을 때만 주장한다.
