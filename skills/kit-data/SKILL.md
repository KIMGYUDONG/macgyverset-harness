# 데이터 진단

설계하기 전에 데이터를 먼저 본다. 실행:

```
python3 macgyverset-harness/scripts/profile_data.py <파일> [--top N] [--json]
```

출력은 행/열 수, 열별 결측 수, 중복 행, 열별 형식 추정, 숫자의 최소/최대, 날짜의 최소/최대, 상위 값이다. 경로는 실제 키트 위치에 맞춘다.

## 해석

| 발견 | 처리 |
|---|---|
| 결측 | 허용되는 값인지 담당자에게 묻는다. 엣지 케이스에 기록 |
| 중복 행 | 같은 데이터인지 다른 사건인지 묻는다 |
| 형식 혼합(숫자 열에 문자) | 입력 검증 규칙으로 정한다 |
| 극단값, 범위 밖 날짜 | 오류인지 실제 값인지 묻는다 |
| 상위 값 쏠림, 낯선 코드 | 코드 의미와 처리 규칙을 묻는다 |

발견은 `docs/edge-cases.md`와 담당자 질문 목록(kit-define)에 옮긴다. 추측으로 데이터를 고치지 않는다.

## 스크립트가 없거나 실패할 때

Python 표준 라이브러리로 직접 확인한다: 행 수, 열 이름, 빈 칸 수, 중복 행, 열별 최소/최대와 상위 5개 값. 큰 파일은 앞부분만 읽고 그 사실을 기록한다. 외부 서비스로 데이터를 보내지 않는다.
