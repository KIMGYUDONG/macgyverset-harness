# 맥가이버셋 하네스 설치와 적용

현재 과제의 작업 루트에 맞는 공개 하네스를 찾고, 해당 저장소의 START.md를 읽어 적용한다. 이 스킬은 해당 환경에 먼저 등록되어야 이름으로 호출할 수 있다. 새 환경이 이 별칭을 이미 안다고 가정하지 않는다. 저장소를 clone하는 것만으로 지침이나 스킬이 자동 실행되지는 않는다.

## 작업 루트와 기존 원본 확인

현재 경로와 과제 안내, 적용되는 AGENTS.md를 확인해 실제 작업 루트를 정한다. 사용자가 명시한 작업 위치를 우선한다. 하네스 저장소 README를 실제 과제 설명으로 해석하지 않는다.

다음 위치에서 실제 디렉터리이며 START.md와 official-skills.lock.json이 함께 있는 원본을 찾는다.

1. `<작업 루트>/macgyverset-harness`
2. 기존 이름인 `<작업 루트>/harness-kit`
3. 현재 저장소 루트. 현재 위치가 저장소 하위라면 먼저 저장소 루트를 확인한다.

마커 두 개로 원본을 확인한 기존 checkout은 그대로 사용한다. 현재 과제 파일이나 같은 이름의 다른 디렉터리를 원본으로 간주하지 않는다. 경로가 심볼릭 링크이면 따라가서 설치하지 않는다. 기존 원본에 pull, reset, checkout, 정리를 실행하지 않는다.

## 원본이 없을 때만 새로 받기

유효한 원본이 없다면 제공 환경에서 허용된 터미널의 git으로 공개 저장소 v0.3.4 태그를 새 `macgyverset-harness` 하위 디렉터리에 받는다. 목적지가 이미 있으면 덮어쓰거나 삭제하지 않고 그 충돌을 보고한다. 별도 AI CLI, 사설 API, 개인 설정과 자격 증명은 연결하지 않는다.

아래 `task_workspace`는 앞에서 확인한 실제 작업 루트로 설정한다.

```bash
git clone --depth 1 --branch v0.3.4 https://github.com/KIMGYUDONG/macgyverset-harness.git "$task_workspace/macgyverset-harness"
git -C "$task_workspace/macgyverset-harness" describe --tags --exact-match
```

새로 받은 디렉터리의 START.md와 official-skills.lock.json, `git describe --tags --exact-match` 결과가 v0.3.4인지 확인한다. 태그가 없거나 다운로드가 차단되면 다른 버전이나 비공개 경로로 우회하지 않고 실패를 보고한다. 이미 찾은 기존 원본을 업데이트하기 위해 이 clone 단계를 실행하지 않는다.

## START.md에 따라 적용

확인한 원본의 START.md를 먼저 읽고 그 안내에 따라 실제 작업 루트에 스킬을 등록하고 적용한다. 경로는 찾은 원본 위치에 맞춘다. 등록된 기존 스킬이 같으면 유지하고 다르면 덮어쓰지 않는다. 루트 AGENTS.md, 전역 스킬, 모델 설정과 권한을 만들거나 바꾸지 않는다.

제공된 Codex와 허용된 모델만 사용한다. 외부 AI, Computer Use, 브라우저/UI 자동 조작을 사용하지 않는다. 시험 입력과 풀이를 외부로 보내거나 Git push, 배포를 실행하지 않는다. 과제 코드와 제출 위치를 하네스에 맞춰 옮기지 않는다.

마지막에는 실제로 사용한 원본 위치, 새로 받은 버전 여부, 등록 결과와 적용한 START.md를 짧게 보고한다. 파일을 찾거나 clone한 결과와 스킬 등록/적용 결과를 구분하며, 확인하지 않은 자동 로드나 실행을 주장하지 않는다.
