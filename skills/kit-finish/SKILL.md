# 제출 준비

과제에서 요구한 파일명, 경로, 형식과 실행 방법을 다시 확인한다. 실제 파일과 저장 상태를 대조하고 필요한 데이터와 코드가 포함됐는지 확인한다. 키트 자체를 과제 결과물로 착각하지 않는다.

선택 이유, 구현 범위, 검사 명령과 결과, 남은 한계를 짧게 정리한다. 과제가 문서 형식을 지정했다면 그것을 따르고 추가 문서를 무조건 만들지 않는다. 수치와 완료 표현은 실제 증거와 맞춘다. 본인이 핵심 흐름과 선택 이유를 이해하도록 설명한다.

종료 직전에는 새 기능을 늘리지 않고 필수 동작과 저장 상태를 확인한다. 플랫폼의 제출 미리보기와 최종 제출은 사용자가 직접 진행한다. 제출물 확정 후 수정할 수 없으며 후속 서술형까지 완료돼야 최종 제출이다. 최종 화면의 제출 ID, 시각, 파일 수와 크기는 사용자가 확인한다.

Git push, 외부 업로드/배포와 UI 자동 제출을 하지 않는다. 후속 서술형에 진입하면 AI 사용을 중단하고 문항을 AI에 전달하거나 답안을 생성하지 않는다.
