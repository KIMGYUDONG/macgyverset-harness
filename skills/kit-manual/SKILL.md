# 매뉴얼 3종

저장 위치는 `docs/manuals/`. 과제가 다른 위치나 이름을 지정하면 그것을 따른다. 쓰기 전에 `docs/board/run.md`의 URL, 포트, 계정을 확인한다.

| 매뉴얼 | 독자 | 템플릿 | 핵심 내용 |
|---|---|---|---|
| 관리자 | 운영자 | [manual-admin](../../templates/manual-admin.md) | 로그인, ID 발급/관리, 주요 기능, 오류 대응 |
| 이용자 | 일반 사용자 | [manual-user](../../templates/manual-user.md) | 접속, 핵심 업무 순서, 화면 설명 |
| 심사 에이전트 | 평가를 수행하는 에이전트 | [manual-reviewer](../../templates/manual-reviewer.md) | 설치/실행, URL, 테스트 계정, 테스트 실행 명령과 기대 결과, 알려진 한계 |

## 규칙

- 명령은 작성 후 직접 실행해 확인한다. 실행하지 않은 명령을 적지 않는다.
- 기대 결과는 실제 출력에서 옮긴다.
- 알려진 한계와 미검증 항목을 숨기지 않는다.
- 과제가 요구하지 않는 매뉴얼은 만들지 않는다. 한 쪽을 넘기지 않는다.
- 비밀번호는 시험용 계정만 적는다.
