# 지시 카드

단계가 바뀔 때 빈칸을 채워 Codex에 입력한다. 내가 정한 판단을 한 줄이라도 넣는다.

```text
[단계] S_
목표: ____
이번에 할 것: ____
하지 않을 것: ____
완료 기준: ____
내 판단과 이유: ____
```

| 시점 | 예시 |
|---|---|
| 시작 | 과제 읽고 요약해 줘. 기존 시스템에서 바뀌는 조건부터 찾아 줘. 코드는 아직 건드리지 마. |
| 담당자 답 받은 뒤 | 담당자 답을 붙여넣을게. 이용자 조회가 관리자 화면보다 우선이야. 이 기준으로 PRD 한 쪽 써 줘. |
| 구현 전 | 핵심 흐름은 ____부터 ____까지야. 이것만 먼저 TDD로 만들어. ____는 나중. |
| 막혔을 때 | 이 오류부터 재현해 줘. 고치기 전에 가설 하나만 말해 줘. |
| 마무리 | 새 기능은 그만. 테스트 결과와 매뉴얼 정리하고 제출 전 점검해 줘. |
