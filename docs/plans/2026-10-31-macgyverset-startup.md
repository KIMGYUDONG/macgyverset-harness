# MacGyverSet Harness v0.2.0

## 변경

- 공개 이름을 맥가이버셋 하네스로 변경하고 설치/적용 진입 스킬을 추가했다.
- AGENTS.md는 하네스 개발에만 적용하고 과제 사용은 명시적인 START.md 읽기로 구분한다. 게시/배포 권한은 환경 정책과 명시적 권한에 따른다.
- START.md 최초 설치/적용 요청은 등록 도구 실행과 결과 확인까지 포함한다. 읽기 전용 검토는 등록/다운로드를 하지 않는다. Git clone 자체가 자동 실행한다고 주장하지 않는다.
- 모델 이름과 effort는 작업별 예시이며 지정 기능이 없으면 허용된 부모 설정을 상속한다. 설정 조회 기능 부재와 모델 미허용을 구분하고 환경의 더 엄격한 guard는 보존한다.
- 기본 위임은 독립 조사/검증, 동시 자식 2개 이하이며 작은 작업과 구현은 메인이 처리한다.

## 검증

- 등록 회귀: macgyverset-harness가 빠지는 테스트를 먼저 실패시킨 뒤 수정했다. 기존 파일 보호/충돌/재실행 검증을 포함한 도구 검사 26개 통과.
- session-handoff writer/loader 회귀 26개 통과.
- 행동 표본은 evals/cases.json의 세 요청을 독립 검토자가 격리된 임시 작업공간에서 수행했다. 작은 수정은 README 한 줄만 바꾸고 재승인이나 추가 절차를 요구하지 않았다.
- 검증 결과만 요청한 사례는 unittest exit 1과 AssertionError 4 != 5를 반환하고 파일을 수정하지 않았다.
- 부모 설정이 허용되고 상속이 보장된 가상 환경에서는 지정/조회 기능이 없어도 독립 조사를 위임할 수 있다고 판단했다. 이 사례는 실제 자식 실행이나 시험 플랫폼 모델 상속의 검증이 아니다.
- 최초 설치 행동 표본: 외부 다운로드 금지 조건으로 START와 진입 스킬을 적용했다. prepare 실행은 installed 9개, 재실행은 unchanged 9개였다. 과제 루트 AGENTS.md 바이트와 clone 파일 해시가 유지됐으며 추가 승인/과제 구현/전역 변경 없이 완료했다. 이는 파일 등록 관찰이며 실제 실행 중 Codex의 catalog 노출 검증은 아니다.
- 임시 표본 디렉터리는 삭제했고 원본 개인 설정을 바꾸지 않았다. 행동 표본은 모든 실행에서의 동일 행동을 보장하지 않는다.

## 호환성

v0.1.0 태그와 기존 소비자 파일은 유지한다. 기존 등록된 8개 스킬 내용은 바꾸지 않고 설치 진입 스킬만 추가하므로 동일 트리 재등록이 가능하다. 기존 clone은 삭제하지 않고 새 이름의 clone을 별도로 사용할 수 있다. 파일 등록과 실행 중인 Codex의 스킬 목록 갱신은 서로 다르며, 시험 플랫폼에서의 즉시 발견은 별도 확인 대상이다.
