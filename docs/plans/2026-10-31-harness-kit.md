# Harness kit v0.1.0

## 승인 범위

공개 Git 키트, 정적 개발 원칙, 7개 kit 스킬과 원본 session-handoff 이식본, 네이티브 역할 지침, 선택적 작업공간 등록 도구를 구현한다. 기존 개인 설정과 원본 지식 DB는 변경하지 않는다.

## 수용 기준

- clone과 START.md 직접 읽기로 사용할 수 있으며 환경 설정 변경이 필수가 아니다.
- prepare는 새 키트 스킬만 만들고 기존 파일과 symlink 경로를 보존한다.
- 동작 검증과 형식/참조 검사를 수행한다.
- 공개 저장소와 v0.1.0 태그를 인증 없이 가져올 수 있다.

## 설계 근거

최근 로컬 사용 기록에서 TDD, 구조 검토, 인계와 탐색/구현 책임이 반복되었다. 재독과 감사 조회가 포함된 횟수를 성공률이나 성능 향상으로 해석하지 않았다. 사용 기록, 개인 경로와 원본 증거는 공개물에 넣지 않았다.

## 추가 반영

- 공식 범용 스킬은 obra/superpowers의 고정 commit에서 원문과 LICENSE를 다운로드한다. SHA-256 lock으로 확인하며 원문을 자동 실행/등록하지 않는다.
- 작업 난도별 모델/effort 시작 기준과 팀장 보고 형식을 추가했다.
- 개인 session-handoff의 writer/loader와 26개 회귀 검사를 함께 이식했다. 개인 경로를 제거하고 시험용 실행 예시에서 clipboard와 전역 변경을 제외했다. 원본 개인 파일은 수정하지 않았다.

## 검증

- 전체: 준비기 16개, 공식 다운로드 10개, 인계 26개로 총 52개 테스트 통과. 8개 스킬 형식 검사와 로컬 참조 검사 통과. gitleaks에서 비밀값 탐지 없음.
- 공식 다운로드: 고정 SHA의 원본 11파일(96,391 bytes)을 실제로 내려받아 해시를 검증했다. 동일 파일 재실행은 네트워크를 사용할 수 없는 상태에서도 unchanged 11개를 반환했다.
- 준비기: 독립 fixture의 복사 실패를 먼저 확인하고 구현했다. checkout이 작업 공간 안에 있는 기본 배치와 재실행, 충돌, symlink를 검사했다.
- 독립 동작 smoke: 격리 Python 예제에서 빈 입력이 None을 반환하는 버그를 재현한 뒤 최소 수정으로 빈 입력/정상 할인/무료 항목 3개 검사가 통과했다. 임시 디렉터리는 삭제했다.
- session-handoff: writer/loader 기존 검사 26개 통과. 자동 hook 설치나 네이티브 새 세션 자동 로딩 성공을 주장하지 않는다.
- 독립 문서 검토에서 발견한 인계 스킬의 clipboard 예시 충돌을 수정했다.

실제 시험 환경과 그 Codex 버전은 이 저장소 제작 환경에서 검증한 것으로 간주하지 않는다.
