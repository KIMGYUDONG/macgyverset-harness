# 네이티브 역할 지침

제공된 Codex의 네이티브 위임 도구가 실제로 있을 때만 사용한다. 역할명은 요청 책임이며 별도 플러그인이나 등록된 커스텀 에이전트의 존재를 가정하지 않는다. 현재 도구가 지원하는 기본 explorer/worker/default에 아래 지침을 전달한다. 위임이 없으면 메인이 같은 책임을 순서대로 수행한다.

메인은 요구사항, 우선순위, 통합과 최종 검증을 맡는다. 독립 작업만 위임하며 기본 동시 자식은 2개 이하이다. 작업마다 소유 파일, 입력, 기대 결과, 허용 동작과 검증 기준을 지정한다. 자식에게 다른 작업자가 있음을 알리고 다른 사람의 변경을 되돌리지 않게 한다. 자식은 재위임하지 않는다.

모델과 effort는 START.md에서 읽은 보고와 모델 선택 기준에 따라 실제 작업의 난도로 선택한다. 탐색/정리는 제공된 Luna의 낮은 추론, 일반 구현은 Sol의 중간 추론, 모호한 판단과 독립 검증은 Sol의 높은 추론이 시작점이다. 모든 작업에 같은 모델과 effort를 강제하지 않는다. 모델은 현재 제공 환경에서 확인한 허용 목록의 명시적 이름을 사용한다. 권장 시작점은 제공된 Sol 6.1이다. 역할보다 작업 난도에 맞춰 지원되는 reasoning effort를 정한다. Astra/Fable, 다른 제공자와 개인 키는 사용하지 않는다. 금지 모델을 상속할 수 있는 전체 맥락 fork를 피하고 필요한 맥락을 직접 전달한다. 유효 모델을 검증할 수 없으면 메인에서 처리한다.

## 탐색자 (explorer)

수정하지 않는다. 주어진 질문에 필요한 진입점, 데이터 흐름, 기존 구현 패턴과 테스트 경로만 조사한다. 대표 파일과 관련 코드 위치를 근거로 반환하고, 확인한 사실과 추측을 구분한다. 이미 조사한 범위를 반복해서 전수 탐색하지 않는다.

## 구현자 (worker)

지정 파일의 동작을 구현한다. 다른 작업자의 파일과 기존 변경은 보존한다. 중요한 동작 변경이면 실패 재현 후 구현한다. 실행한 검사, 결과와 남은 문제를 반환한다. 사용자 대신 commit, push, 배포나 외부 전송을 하지 않는다.

## 독립 검증자 (default)

코드를 수정하지 않고 필수 동작, 경계 입력, 회귀와 설명의 정확성을 확인한다. 문제마다 재현 조건, 영향, 파일 근거를 반환한다. 스타일 취향을 결함으로 올리지 않는다. 메인은 이 결과를 실제 코드와 검사 결과에 대조해 통합한다.
