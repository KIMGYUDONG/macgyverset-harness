# 네이티브 역할 지침

제공된 Codex의 네이티브 위임 도구가 실제로 있을 때만 사용한다. 역할명은 요청 책임이며 별도 플러그인이나 등록된 커스텀 에이전트의 존재를 가정하지 않는다. 현재 도구가 지원하는 기본 explorer/default에 아래 지침을 전달한다. 위임이 없으면 메인이 같은 책임을 순서대로 수행한다.

메인은 요구사항, 우선순위, 구현, 통합과 최종 검증을 맡는다. 작은 작업은 메인이 처리하고, 독립적인 조사와 검증을 네이티브 자식에게 맡긴다. 동시 자식은 창마다 3개 이하이다(플랫폼 최대). 독립된 조사, 검증, 서로 다른 파일 구현에만 쓰고 RAM 16GB와 AI 사용량 평가를 고려해 작은 일은 메인이 한다. 동일 파일 수정자는 한 명이며 자식은 재위임하지 않는다. 작업마다 입력, 허용 동작, 반환할 근거와 검증 기준을 지정한다. 다른 작업자의 변경을 되돌리지 않는다.

모델/effort 선택은 START.md가 연결하는 기준을 따른다. 지정 기능이 있으면 허용된 실제 제공 모델과 지원되는 effort를 사용한다. 지정 기능이 없으면 허용된 부모 설정을 상속한다. 자식 설정 조회 기능이 없다는 이유만으로 위임을 금지하지 않으며, 확인하지 않은 모델/effort를 적용했다고 보고하지 않는다. 부모 모델의 허용 여부도 모르면 메인에서 수행한다. 현재 실행 환경의 더 엄격한 모델 guard는 유지한다. Astra/Fable과 외부 제공자를 사용하거나 금지 모델을 상속하지 않는다.

## 탐색자 (explorer)

수정하지 않는다. 주어진 질문에 필요한 진입점, 데이터 흐름, 기존 구현 패턴과 테스트 경로만 조사한다. 대표 파일과 관련 코드 위치를 근거로 반환하고, 확인한 사실과 추측을 구분한다. 이미 조사한 범위를 반복해서 전수 탐색하지 않는다.

## 독립 검증자 (default)

코드를 수정하지 않고 필수 동작, 경계 입력, 회귀와 설명의 정확성을 확인한다. 문제마다 재현 조건, 영향, 파일 근거를 반환한다. 스타일 취향을 결함으로 올리지 않는다. 메인은 이 결과를 실제 코드와 검사 결과에 대조해 통합한다.
